# BINUS @Bekasi - Game Your Future Portal 🎮

Selamat datang di **Game Your Future Portal**, portal simulasi interaktif yang dirancang khusus untuk mengenalkan kurikulum dan keahlian di program **Business Information Technology (Business IT)** & **Digital Business Innovation (DBI)** BINUS University @Bekasi kepada siswa SMA/K.

Aplikasi web ini menggabungkan prinsip gamifikasi dengan studi kasus nyata di dunia bisnis siber untuk memberikan gambaran menyenangkan tentang bagaimana teknologi informasi menggerakkan masa depan industri global.

---

## 🚀 Fitur Utama & Modul Game

### 1. 🐧 Polar IT Portal (Polar Penguin Game)
Pemain memimpin tim pinguin siber dalam mengelola infrastruktur data dan bisnis di wilayah kutub melalui 5 stasiun pipeline:
*   **Modul 1: Penguin Market Tycoon (E-Commerce & Analytics)**  
    Simulasi *demand forecasting* dan penentuan harga pasokan berdasarkan kondisi cuaca kutub dinamis untuk melatih insting analisis pasar.
*   **Modul 2: Igloo Network Architect (System Topology)**  
    Merancang skema redundansi jaringan untuk menghubungkan Igloo Server utama dengan Igloo Client tanpa melewati retakan es siber yang berbahaya.
*   **Modul 3: Polar Trendsetter (Digital Marketing)**  
    Menyusun strategi konten media sosial menggunakan kombinasi tagar (*hashtag*) yang tepat demi menjangkau target pasar yang pas secara optimal.
*   **Modul 4: Data Stream Sorter (Database Management)**  
    Mengklasifikasikan paket data yang mengalir deras (*data transaction, metadata, error log*) ke tabel basis data relasional yang sesuai secara real-time.
*   **Modul 5: Expedition Sprint (Agile Project Management)**  
    Game taktis berbasis turn (*turn-based resource allocation*) untuk mengorganisasikan tim ekspedisi Agile (Scout, Engineer, Medic, Analyst, Leader) melewati rintangan alam dengan Action Points (AP) terbatas.

### 2. 🚀 ORBIT Adventure
Petualangan siber bertema luar angkasa yang membedah konsep *Enterprise Technology*, pengenalan kecerdasan buatan (*AI for Business*), serta peta karir profesional di sektor IT.

### 3. 🦄 Startup Destiny RPG
Simulasi kepemimpinan berwirausaha (*technopreneurship*) di mana pemain membuat keputusan-keputusan krusial di 7 fase pertumbuhan startup teknologi untuk melatih manajemen risiko dan *design thinking*.

## 🛠️ Tech Stack & Desain Sistem

Portal ini dibangun dengan performa tinggi dan desain visual premium:
*   **Frontend**: React 18+ (JSX)
*   **Desain Estetika**: Cyberpunk futuristik dengan neon border, latar belakang grid siber dinamis, partikel animasi sferis, dan efek transisi booting konsol.
*   **Audio**: Web Audio API Synthesizer (suara retro mini-synth untuk umpan balik interaksi pengguna tanpa memperberat bundle aplikasi).
*   **Aksesibilitas UI/UX**: Tata letak terpadu (*Unified Layout*) dengan ukuran teks nyaman dibaca (minimal 12px untuk deskripsi, 16px untuk tajuk) dan area interaksi ramah layar sentuh (*mobile zone*).

## 🏁 Cara Menjalankan Project Secara Lokal

1.  **Instalasi Dependensi**:
    ```bash
    npm install
    ```
2.  **Menjalankan Mode Development**:
    ```bash
    npm run start
    ```
3.  **Membangun Bundel Produksi (Build)**:
    ```bash
    npm run build
    ```
    Bundel produksi yang dihasilkan dioptimalkan secara kompresi gzip hingga berukuran sangat ringan (~143 kB) agar cepat dimuat di perangkat seluler siswa.
